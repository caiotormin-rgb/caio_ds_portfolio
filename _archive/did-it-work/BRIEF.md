# Did It Actually Work?
*(the rigor project — do this third)*

**ONE MESSAGE (locked):**
> [Policy X] looked like it worked. Against a synthetic counterfactual built
> from comparable municipalities, [it did / most of the effect was already
> happening anyway].

**Sells:** incrementality, causal inference, geo-lift testing. This is the
credibility skill marketing science teams screen hardest for — same math as
"did the campaign actually drive sales."

## AUDIENCE + DECISION  *(draft — Caio's call)*
**Who acts on this:** whoever decides to renew, expand, or kill the program.
**What they do differently:** renew or don't — and stop crediting the program
with change that was already in the pre-trend.
**Layer 1 sentence they must leave with:** "Of the observed X% change, Y% was
incremental to the policy."

## Data
Any staggered policy rollout with municipal or state panel data. Choose at
step 0, then lock it.

## Method (do not exceed)
- Difference-in-differences, or synthetic control for the treated unit.
- Placebo test. Pre-trend check. These are non-negotiable — they ARE the project.

## Chart budget: 3
1. Treated vs synthetic counterfactual over time.
2. Placebo / permutation distribution.
3. Effect size with uncertainty.

## OUT OF SCOPE
- Multiple policies. One.
- Anything beyond DiD / synthetic control.

## DONE WHEN
- [ ] Pre-trends shown honestly, even if they're ugly
- [ ] Placebo test run and reported
- [ ] 3 charts
- [ ] Writeup that states the counterfactual number up front
